# Future Display-Only Add-On

No executable JAR is generated from this directory.

This reserved boundary is for a future BookmapData real-time add-on only after
the Developer Agreement and Bookmap server-side approval are complete. That
JAR must have a distinct module name, a unique filename, `@UnrestrictedData`,
and no file, network, clipboard, MCP, or notification output. It must never
depend on the delayed/Replay JSONL collector.
