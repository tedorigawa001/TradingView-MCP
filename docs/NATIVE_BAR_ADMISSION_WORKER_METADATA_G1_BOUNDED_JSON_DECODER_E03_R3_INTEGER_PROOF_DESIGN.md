## L0-L8 derivations (cap4736)
L0 Representation/rounding (ES4 Q1/Q3, ES5 Q1, ES6 Q5). Any mathematical integer z in 1..M is representable. Its distance from itself is zero, so nearest-value rounding selects it without a tie. At z=0, the recorded rule removes -0 from the selection set and restores it iff x<0; mathematical 0 is not negative, so F(0)=+0. Thus F(z) is the canonical D representative for z in 0..M. This is a derivation, not a quoted fact; it covers no nonintegral or out-of-domain result.

L1 Comparison (ES4 Q4, Q1; ES5 Q5). For A,B in D, NaN and infinities are absent and +0 is the only zero, so R is one-to-one on D and equal(A,B) is true iff a=b; b>0 means equal(B,+0) is false. lessThan's same-value and zero case results are not recorded, so it is used only for positive A,B with equal false. Reading L1-R, from the case names: its same-value, zero and infinity cases fire only for equal, zero or infinite operands, and its real comparison gives a<b; so here lessThan gives a<b. A guard u<=v, tested in this order, is true if equal(U,V) or equal(U,+0), false if equal(V,+0), else lessThan(U,V). This justifies abstract guards only. Actual language comparisons and zero-test bindings stay OPEN; comparison alone cannot check an arbitrary input.

L2 Subtraction (ES6 Q2/Q1, ES5 Q5, L1, L0). Guard b<=a. Then integer z=a-b satisfies 0<=z<=a<=M. If b>0, internal unaryMinus(B) represents -b; A is positive by the guard. Finite add reaches F(a-b), including F(0) for equal positives. If b=0 its negation is -0, whose R is 0: A=+0 combined with it reaches F(0), and positive A reaches F(a). NumSubtract therefore returns exact canonical z, +0 when z=0. Internal negative values are not retained in R3.

L3 Addition (ES6 Q1, L2, L1, L0). Guard a<=M-b, computing NumSubtract(F(M),B) by L2 from checked inputs. Then integer z=a+b is in 0..M. Canonical inputs cannot both be -0; NaN/infinity cases are absent. Add reaches F(z), exact/canonical by L0; 0+0 gives F(0)=+0. No out-of-range computed candidate is used to implement this pre-guard; without it there is no success claim.

L4 Remainder (ES4 Q2, ES5 Q3, ES6 Q3, L1, L0). Guard b>0. At a=0 the zero-dividend branch returns canonical +0, representing r=0. Otherwise a,b are positive finite integers, so earlier NaN/infinity/zero cases are absent. Mathematically q0=truncate(a/b)=floor(a/b), hence q0<=a/b<q0+1. Define r=a-b*q0; r is an integer and 0<=r<b<=M. The negative-dividend -0 branch is absent. NumRemainder reaches F(r), exact and canonical by L0. The proof's b*q0 is mathematical, not a computed Number product; no Math.trunc/floor is invoked.

L5 Exact division (ES6 Q3, L4, L1, L0). Guards b>0 and L4 remainder r=0. At a=0, zero by positive B returns +0. Otherwise a/b is a positive integer<=a<=M; finite positive operands reach F(a/b), exact/canonical by L0. A nonzero remainder refuses exact-integer division: no rounded rational quotient enters a field.

L6 Floor quotient (L4, L2, L5, L1). Guard b>0. Obtain the Number for r by L4, then the Number for d=a-r by L2 (L2's guard r<=a holds by proof: r=a-b*q0 with b*q0>=0). d is divisible by b, so L5's remainder guard holds by proof and no second remainder is computed; L5 yields q=d/b=floor(a/b) in 0..M. L7 Multiplication (ES6 Q1, L6, L1, L0). If either input is zero, an explicit branch returns +0. Otherwise a,b>0. Compute t=floor(M/a) by L6 and require b<=t before multiplying. Integer z=a*b<=M; finite positive operands reach F(z), exact by L0. The threshold uses no application multiplication, avoiding circularity.
