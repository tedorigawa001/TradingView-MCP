# 登録済みSMAクロスv2の純粋計算部

対象は `sma-cross-adj-30m60m-1y-20261114-v2`、定義ハッシュは `sha256:8dc5c2d46af53161f69fe8427403510b8bfb247e486fcccab152b27c6a5b3573`。定義schema自体は既存の `measurement_hypothesis_v1` のままである。v1研究・登録ジャーナルは変更しない。

`src/smaCrossMeasurement.ts` は明示呼出し型の純粋計算モジュール。チャート・ネットワーク・ファイル・環境設定・研究登録にアクセスせず、時刻の現在値も読まない。Nodeのcryptoのみを実行時に使用する。研究型へのimportは型専用で、保存クラスをロードしない。公開MCPツール、CLI、DOT、サーバーへの接続は追加していない。

## 入口と信頼境界

`measureSmaCrossV2` は登録定義本文・定義ハッシュ・0〜4系列・任意の群別推論前提を受け取る。定義のキー構造と正規化後ハッシュを検査し、別ID、別期間、別定義、未知の定義項目を拒否する。

対象はOANDA:EURUSD/XAUUSD、30/60分足、終値SMAの10/40・40/60・60/90・90/120の固定16群。欠けている系列を補完せず、該当群を保留して補正枠を維持する。未知・重複系列や疎配列、順序不正、不正価格は全体停止。

`NativeSmaSeries` は配信元と時間足、`confirmed_bar_end_utc_ms`という時刻契約、ネイティブ系列の根拠参照、期間網羅性の宣言と根拠参照、バー列を持つ。各バーには開始・終了時刻、終値、確定フラグ・確認時刻・根拠、前バーからの連続性分類と根拠を要求する。

供給元・セッション・連続性・期間網羅性・観測独立性の根拠は、承認された入力アダプタから供給されることを前提とする。文字列の存在は資料の真正性や内容を証明しない。本モジュールは資料を取得・認証しないため、出力には `sourceEvidenceIsCallerSupplied` と `inferenceEvidenceIsCallerSupplied` を明示する。実データ用アダプタ、原データの固定・出所照合・取得上限は未実装で別承認。

期間網羅性は`coverage.from/through/tail/evidenceRef`で明示する。通常の連続末尾では最後の対象バーから次の時間足までが終端に届くことも検査する。長い末尾休場は明示された休場分類と根拠が必要であり、時刻差だけで休場と認定しない。中間の空白も同様。根拠不足、未確定、終値欠落は系列の群を保留する。補間・前方補完・並替え・無断のバー削除はしない。

## 時刻と状態

期間はUTC `[2025-11-14T04:57:31Z,2026-11-14T04:57:31Z)`。内部時刻はUTC整数ミリ秒のバー終了時刻であり、取得・確認観測時刻とは別。後日の確認は過去時点での可視性を証明しない。終了時刻が終端以上のバーの価格・確定フラグは測定に使わない。原データの単位変換や終了時刻の推測は入力アダプタの仕事であり、本モジュールでは行わない。

各群は最初の起点を保持し、同方向再発と同値を無視する。逆クロスで終了・同足で次区間開始。期間直前の最後の非ゼロSMA差で左端状態を初期化し、左端継続区間は対象外とする。方向不明は保留し、右端未完は打切り。区間は群IDとordinalで識別できる。両端打切りは1区間に両フラグを持ち、ユニーク区間総数を二重計上しない。

SMAの大小比較は、入力された正の有限binary64値を`2^-1074`の共通単位へ正確に変換したBigInt窓和で行う。通常数・非正規化数を同じ尺度で扱い、120本固定リングから古い値を正確に引き、新しい値を正確に足す。平均値へ丸めず、`sum_fast * slow - sum_slow * fast`の符号を使う。大きな値が窓から抜けても有限誤差を持ち越さず、丸めた平均が同値になる場合もクロスを誤って消さない。epsilonや価格の補正は導入しない。

正の有限binary64入力の単位整数は2098 bits以内、120本以下の窓和は2105 bits以内、比較用の積は2112 bits以内である。保持する正確な値は120本リングと5窓和で、系列全体には4組の符号だけを保持する。任意精度の桁数や窓長を入力で増やす機能はない。窓更新1回の計数と既存の停止閾値は維持する。

これは受け取ったbinary64値そのものに対する正確な平均の大小比較であり、元の十進文字列の復元や、Pineの丸め済みSMAとのビット一致を意味しない。実データの出所・数値的妥当性、Pineとの実機同等性は未確認。区間状態の独立した検証用入口は従来の数値SMA点も扱えるが、測定本体は正確な窓和から作った符号点を渡す。矛盾した二重表現や不正な符号値は拒否する。

## 統計と報告

完結区間のみの `s * ln(Cu/Ct)` を使う。ゼロ分散、30観測未満、非有限計算は保留。t値は不偏標本分散を用い、Student tの両側p値は正規化不完全ベータ関数で計算する。連分数は256反復までで、収束しなければ保留し別手法へ切り替えない。

観測独立性等の前提が根拠参照付きで宣言されない限り、記述的なt値が算出できてもp値を採用しない。根拠宣言はモジュールが前提の成立を実証した意味ではない。

Holmは固定16枠・有意水準0.05。評価不能群は補正入力をp=1とし、実際の判定はheld。上昇・下降を別検定へ増やさない。全体停止時は先行区間・統計を保持し、Holm判定は未確定として返す。

`observationsKnown=false`の群は、処理された観測数が0でも母集団の区間数が0という意味ではない。品質理由は`qualityFlagCounts`に別集計し、不明な保留区間数はnull。共有系列の品質フラグを4群分合算して独立した異常バー数とは扱わない。確定した区間には完結・左・右・両端・ユニーク打切り数を返す。

`status=complete`は指定入力の計算・保留判定を終えたことのみ。原データ全体の完全性や統計的前提の成立、監視採用を意味しない。`executionAllowed`と`adoptionAllowed`は常にfalse。

## 停止閾値

以下はすべて未満だけを許容する固定の閾値で、引上げやリセットの入力は持たない。

| 対象 | 閾値 |
|---|---:|
| 入力バー／1系列 | 65536 |
| 入力バー／全4系列 | 262144 |
| 初期方向探索／1群 | 8192点 |
| 生成区間／1群 | 8192件 |
| 生成区間／全群 | 65536件 |
| 全体の処理単位 | 4194304 |
| 出力UTF-8 bytes | 8388608 |

処理単位は入力・派生点の1件検証、SMAの1期間1更新、群の1バー状態評価、初期探索1点、区間1件の集約を計数し、固定16枠の順位処理にも保守的に256単位を課す。これは全CPU命令数や壁時計時間の保証ではない。p値の内部反復は上記の別上限を持つ。

出力は固定メタデータ用32768 bytesを見込み、区間追加前にそのJSONサイズを計数する。停止報告用1024 bytesを確保し、最終JSONのUTF-8サイズも検査する。上限で切り詰めて成功扱いにしない。停止済みbudgetは別群でも再利用できない。

全体停止では先行結果、理由、処理済み群・未処理群、検証済み入力行数・残り行数、処理単位数を保持する。不明な残り行数はnull。行数は供給された配列についての値であり、供給元全履歴の件数ではない。

## 検証範囲と制約

専用テストは架空の価格・暦・根拠参照だけを使う。状態遷移、期間境界、初期化不足、打切り、停止閾値、先行結果、品質理由、16群分離、Holmの独立期待値を確認する。Student t参照値は別方式の有限cos冪積分漸化式から固定し、区間抽出も非ゼロ符号列を圧縮する別実装と照合する。

窓和のP2回帰テストは、毎回の窓を直接BigIntで加算する独立基準と4組全ての区間境界・方向・観測数を照合する。大きな値の退出、平均丸めによる同値、2の冪によるスケーリング、非正規化数、最大側の通常数、最大有限値から非正規化数への退出を含む。基準は整数・既知の共通尺度を使い、本体のbinary64デコーダやリング窓和・状態遷移関数を再利用しない。

実データ取得・測定、チャート変更、研究の追加登録、DOT起動、外部モデル、バックテスト、コミットは行わない。既存STOPとno-retry、未配分765 bytesは維持し、本実装のファイルサイズや処理容量を既存枠へ推測で充当しない。
